# IPTV Player (Android TV)
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab > **Build APK** > wait for green > download the `IPTV-Player-APK` artifact (zip containing app-debug.apk).
3. Put the APK on your Android TV (USB stick / "Send files to TV" / Downloader app) and install.
